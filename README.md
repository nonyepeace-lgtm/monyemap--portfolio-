# MoneyMap — Interactive Personal Finance Dashboard

MoneyMap is a responsive, browser-based personal finance dashboard concept built to make everyday money decisions easier to understand. It brings a financial overview, budget planning, bills, savings goals, tax-planning workspace, reports, and preferences into one interface.

## Project status

**Interactive front-end prototype.** This repository currently contains a standalone HTML/CSS/JavaScript interface. It uses illustrative sample figures and does not connect to bank accounts, store user data, submit tax filings, or provide regulated financial advice.

## Features

- Dashboard overview and available-to-spend summary
- Personal finance overview
- Budget and safe-to-spend concept
- Bills and upcoming payment list
- Savings-goal progress concept
- Tax-planning workspace placeholder
- Reports and preferences sections
- Responsive layout and navigation between sections

## Run locally

No package installation is required for the current static prototype.

1. Clone or download this repository.
2. Open `index.html` in a modern browser.
3. Use the left navigation to explore the dashboard sections.

For local development, a static server can also be used, for example:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Technology

- HTML5
- CSS3 (responsive layout)
- Vanilla JavaScript

## Privacy and security note

Do not enter real bank credentials, personal identifiers, or confidential financial data into this prototype. The figures shown are examples for demonstration.

## Portfolio context

This project demonstrates front-end layout, navigation, dashboard information architecture, and early product thinking for a personal-finance tool. It is a prototype, not a production banking application.
